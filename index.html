Monthly Inspection

Monthly Maintenance List

Our certified technicians perform the following comprehensive checks every month on every maintained lift — covering five key areas of the lift system.

Shaft Interior Work — 10 Inspection Points
# Inspection Task Done
1 Check whether main and counter guide rail oil levels are correct, re-oil if needed, and verify rack plates are in place.
2 Check if every traction rope has equal and correct tension.
3 Check if all flexible cables are in normal condition.
4 Check if the speed governor rope tension is correct.
5 Check if the preliminary and final limit switches operate correctly.
6 Check that all safety work and magnetic bar positions are correct.
7 Check if shaft lighting, buzzer, and pit area are clean and working.
8 Check if the counter weight is making any abnormal noise.
9 Check if counter weight rollers from top to bottom are tight and properly mounted.
10 Check if the main guide shoe is in correct condition.
Landing Door Work — 4 Inspection Points
# Inspection Task Done
1 Check if the landing door mechanical and electrical contacts are in normal operating condition.
2 Check if door seals are clean and in normal working condition.
3 Check if landing door hanger rollers and opening rollers are correctly adjusted.
4 Check if landing door wired rope, door lock, and door closer are in correct condition.
Cabin & Cabin Door — 10 Inspection Points
# Inspection Task Done
1 Check if the emergency brake and releasing rod are in normal working condition.
2 Check if guide shoes are clean and if there is sufficient oil on the oiling pad.
3 Check if the emergency brake and releasing rod operate normally.
4 Check if the photoelectric cell is functioning correctly.
5 Check if the cabin seals are clean.
6 Check if the door motor and motor gear are operating normally. Check gear oil level and lubrication.
7 Check if door contacts and contact pins are electrically connected properly.
8 Check if the door C.P.U. camera view is clear and camera roller is in correct position.
9 Check if the cabin door guide shoe and roller are in correct condition.
10 In case of power failure, test the emergency battery function inside the cabin.
Machine Room — 7 Inspection Points
# Inspection Task Done
1 Check if the control box interior and exterior parts are clean.
2 Check if the gear oil level and quality (viscosity) are within correct specifications.
3 Check if the gear oil-seal is leaking oil.
4 Check if the main motor and gear make any abnormal noise during operation.
5 Check if the over speed governor is clean and lubricated where necessary.
6 Check if the speed governor roller is in correct condition.
7 Check if emergency caller indicator, intercom, and buzzer operate correctly (especially in case of power failure).
Others — 2 Inspection Points
# Inspection Task Done
1 Check if every cabin and landing floor operation is functioning correctly.
2 Check if the cabin and every door outer floor indicator is displaying correctly.
